# Sequential Modules

A collection of clock-driven digital designs implemented in Verilog, focusing on storage, state transitions, and sequential RTL design.

## 📌 Overview

This section focuses on understanding how digital systems behave over time using clock and reset signals.

The designs are implemented using different Verilog coding approaches wherever applicable, allowing the same functionality to be studied from different perspectives.

## 💡 Coding Styles

Different Verilog coding styles are explored to understand how sequential hardware can be described at different abstraction levels.

The implementations focus on writing clear, modular, and simulation-friendly RTL.

## 🧪 Verification

Every design includes a dedicated **testbench** for functional verification.

Testbenches are used to:

* Generate clock and reset signals
* Apply different input conditions
* Verify state transitions
* Check expected outputs
* Validate functionality through simulation

## 🔹 Topics

* Flip-Flops
* Latches
* Registers
* Counters
* Shift Registers
* Memory-Based Designs
* Finite State Machines (FSMs)
* Clock and Reset Logic
* Sequential RTL

## 🎯 Objective

To build strong practical skills in sequential logic, Verilog RTL coding, simulation, and functional verification while gaining experience with different coding approaches.
